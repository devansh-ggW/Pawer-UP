# PawerUP — by DEWIFY

PawerUP is DEWIFY's pet-products storefront. This first version recreates the broad content flow of the Voldog reference site with original PawerUP branding and English copy.

## Current build

- Responsive homepage and navigation
- Food, treats, toys and pet-care category sections
- Dog preference finder (browsing suggestions only; not veterinary or feeding advice)
- Sample product cards and front-end preview bag
- FAQ, newsletter preview and DEWIFY contact details

## Important first-version notes

- Product cards are catalogue placeholders, not confirmed inventory.
- Prices, supplier availability, delivery promises, real checkout, payment processing and newsletter storage are not connected yet.
- Replace sample imagery with approved PawerUP product/lifestyle images before launch.
- Add real product data only after supplier selection and margin checks.

## Preview locally

Open `index.html` in a browser. No build step or package installation is required.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub Pages will publish the static site after deployment completes.
